# PT650 — منصة اللياقة والتدريب

PT650 مشروع مخصص لتتبع التدريب واللياقة وإدارة التقدم، بواجهة عربية وتطبيق ويب قابل للتثبيت. هذا الإصدار يُطوَّر تحت هوية PT650 التابعة لإمدادات.

## حالة الفصل التقني

- **الواجهة الحالية (قائمة):** https://alalmaiesa-glitch.github.io/openGym/
- **الاستضافة الجديدة (قائمة):** https://pt650.vercel.app/
- **مصدر الشيفرة الحالي:** `alalmaiesa-glitch/openGym` (مستودع متفرع من openGym).
- **المستودع المستقل المستهدف:** `alalmaiesa-glitch/pt650` — لم يُنشأ بعد؛ لا يُعد الفصل عن علاقة Fork مكتملاً قبل النقل والتحقق.
- **الخدمات:** PT650 Supabase Auth و`pt650-platform` Edge Function، دون نقل قاعدة بيانات أو أسرار.
- **إصدار الويب الجديد:** يبنى من `frontend/` باستخدام `npm ci` و`npm run build`، مع `VITE_DEMO=1` لمضاهاة إعداد نشر GitHub Pages الحالي.

## تطوير واختبار الواجهة

```bash
cd frontend
npm ci
npm test
npm run build
```

**تنبيه:** لا تُبدّل إعدادات Supabase أو هوية تطبيق الجوال أو نطاق المصادقة تلقائيًا أثناء نقل الاستضافة. تخزين الجلسات داخل المتصفح مرتبط بكل نطاق، لذا قد يحتاج المستخدم إلى تسجيل الدخول مجددًا على الرابط الجديد.
